# NOTICE — arc-ui (espelho não oficial do uiarc.dev)

Este repositório é um espelho **não oficial** de <https://uiarc.dev/components>, feito para estudo, demonstração e uso livre. Não é afiliado ao uiarc.dev nem endossado pelo seu autor.

## De onde vem o conteúdo

- **Itens free (143):** arquivos de registro publicados publicamente pelo uiarc.dev, redistribuídos sem alteração de lógica — apenas re-empacotados para rodar fora do site.
- **Itens Pro (242):** o conteúdo foi obtido dos **bundles JavaScript/CSS públicos** que o próprio site publica — os mesmos artefatos que o navegador de qualquer visitante baixa ao abrir uma página do uiarc.dev. A extração é mecânica (desempacotamento dos módulos webpack servidos via HTTPS); não houve acesso a repositório privado, fonte interna ou CLI. Os **termos de uso e de licença do uiarc.dev se aplicam a todo o conteúdo**; o código já chega ao público nesses bundles.
- **Demais itens free (60):** reconstruídos a partir dos arquivos-fonte publicados, compilados para bundles autossuficientes com props de demonstração geradas automaticamente ou curadas manualmente (os demos desses itens não são exatamente o código de demonstração do site).
- **Design tokens, tipografia (Geist/Inter) e ícones:** extraídos do CSS e das fontes públicas do site.

## Resposta à solicitação

Para remover este espelho ou qualquer item específico, basta abrir uma issue em [nevusdigital/arc-ui](https://github.com/nevusdigital/arc-ui) — será atendida.
